# Lab Space Planner

Interactive browser-based 2D laboratory layout planner. Static HTML/CSS/JavaScript; no build step or backend.

## Features
- Editable room dimensions, scaled 50 cm grid
- Doors, windows, lab equipment and custom objects
- Drag, rotate, resize, duplicate, delete
- Overlap/out-of-bounds checks
- Save/load in browser, import/export JSON, export SVG

## Deploy
Import this repository into Vercel as an **Other** framework / static website. No build command is needed; root output directory is `.`.

## Limitations
For conceptual planning only. No validated door-swing clearances, utility routing, or regulatory safety assessment.
